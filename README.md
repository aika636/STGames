# STGames

[![SillyTavern extension](https://img.shields.io/badge/SillyTavern-extension-blue)](https://github.com/SillyTavern/SillyTavern)
[![version](https://img.shields.io/badge/version-0.10.0-informational)](manifest.json)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**Мини-игры для [SillyTavern](https://github.com/SillyTavern/SillyTavern):** платформа с
хабом, из которого открываются игры в модальном окне поверх чата. Сейчас в каталоге восемь
игр — судоку, змейка, реверси, слова, сапёр, нонограмма, кроссворд и балда. Открывается из меню «волшебной палочки» (пункт «STGames») или
командой `/stgames`, закрывается по Esc — и чат остаётся ровно там, где вы его оставили.

Игры генерируются и исполняются **локально в браузере**: сетевых запросов нет, а LLM в них
не участвует — чат не читается и не пишется.

## Игры

### Судоку

Классическая головоломка 9×9. Пазлы генерируются на месте: полное решение строится
перебором с возвратом, затем клетки выкалываются с проверкой того, что решение осталось
единственным. Готовых наборов пазлов нет, поэтому одинаковых досок вы не увидите.

- 🎲 **Четыре уровня** — лёгкий, средний, сложный, эксперт; сложность оценивается по
  технике, которой хватает для решения, а не по числу подсказок.
- ⌨️ **Ввод с клавиатуры** — `1`–`9`, стрелки, `Del`.
- 📱 **И с телефона** — ряд цифр под доской: он же показывает, сколько каждой цифры
  осталось выставить.
- ✏️ **Заметки-кандидаты** (`N`) с автоочисткой у соседних клеток.
- ↩️ **Undo/Redo** (`Ctrl+Z` / `Ctrl+Y`) — откатывается и авточистка заметок.
- 🔴 **Подсветка конфликтов** и, по желанию, **ошибочных цифр**.
- ⏱️ **Таймер** партии; на паузе, пока окно закрыто.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли снова
  и продолжили с того же места.
- 📊 **Статистика по уровням** — сыграно, решено и лучшее время; видна в панели настроек.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Выбрать клетку | стрелки | клик (повторный — снять выделение) |
| Поставить/снять цифру | `1`–`9` | тап по цифре в ряду под доской |
| Стереть | `0`, `Delete`, `Backspace` | «Стереть» |
| Режим заметок | `N` / `Т` | «Заметки» |
| Отменить / вернуть | `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | «Отменить» / «Вернуть» |
| Закрыть окно | `Esc` | крестик в углу |

Повторный ввод той же цифры стирает её — отдельная кнопка «стереть» нужна редко.
Клавиши, которые игра обработала, до чата не доходят; всё остальное проходит к SillyTavern
насквозь.

Партия сохраняется сама — после каждого хода. Кнопка «Новая игра», смена уровня в окне
и `/sudoku <уровень>` начинают новую доску поверх сохранённой; кнопка в хабе и просто
`/sudoku` продолжают начатую.

#### Настройки

Панель **Extensions** → блок **Судоку**:

| Настройка | Что делает |
|---|---|
| Уровень сложности | С каким уровнем стартует новая партия |
| Подсвечивать конфликты | Красит клетки, которые спорят по строке, столбцу или боксу |
| Подсвечивать ошибочные цифры | Сверяет доску с решением и отмечает неверные цифры (по умолчанию выключено — это подсказка) |
| Автоматически убирать заметки | Убирает поставленную цифру из заметок соседних клеток |
| Показывать таймер | Время партии в шапке окна |

### Змейка

Классическая аркада на поле 21×21. Змейка ползёт сама, вы управляете направлением —
стрелками, свайпами по полю или d-pad'ом под ним.

- 🐍 **Счёт и длина** — счёт растёт за каждое съеденное яблоко, змейка удлиняется.
- ⏸️ **Пауза** — при уходе со вкладки или из окна игра сама ставится на паузу:
  вернувшись, вы не обнаружите труп.
- 🏆 **Рекорды сохраняются** — лучший счёт, лучшая длина и число сыгранных заездов
  лежат в панели настроек. Сам заезд сохранять нечего: смерть (или победа на полной
  доске) начинают новую партию.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Повернуть | стрелки / `W` `A` `S` `D` (и ЙЦУКЕН) | свайп по полю или стрелка на d-pad |
| Пауза | `Space` | кнопка на d-pad |
| Закрыть окно | `Esc` | крестик в углу |

### Реверси

Партия против соперника на доске 8×8. Ставите фишку так, чтобы зажать ряд чужих между
своими, — и весь ряд переворачивается. Побеждает тот, чьих фишек больше, когда ходов
не осталось ни у кого.

- 🤖 **Три уровня соперника** — перебором с альфа-бета-отсечением на глубину 1, 3 и 5;
  концовку (последние ≤ 10 пустых клеток) он досчитывает точно и не ошибается.
- ⚫ **Игра чёрными или белыми** — чёрные ходят первыми, так что игра белыми означает,
  что первый ход делает соперник.
- 💡 **Подсветка доступных ходов** — по желанию, отключается в настройках.
- ⏭️ **Пас объявляется** — если ходов нет у одной из сторон, игра скажет об этом, а не
  вернёт ход «сам собой».
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли снова
  и доиграли.
- 📊 **Статистика по уровням** — сыграно, побед, поражений, ничьих и лучший разрыв.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Двигать курсор | стрелки | — |
| Поставить фишку | `Enter` / `Space` | клик по клетке |
| Новая партия | — | кнопка «Новая игра» |
| Закрыть окно | `Esc` | крестик в углу |

`/reversi <уровень>` открывает игру сразу с нужным соперником и начинает новую партию;
просто `/reversi` или плитка в хабе продолжают сохранённую.

#### Настройки

Панель **Extensions** → блок **Реверси**:

| Настройка | Что делает |
|---|---|
| Уровень соперника | Глубина расчёта: лёгкий, средний, сложный. Применяется сразу, в том числе к идущей партии |
| Играть | Чёрными или белыми; подхватывается следующей партией |
| Подсвечивать доступные ходы | Точки на клетках, куда можно сходить |

### Слова

Русский вордл: слово из пяти букв за шесть попыток. После каждой догадки плитки
раскрашиваются — зелёная буква стоит на месте, жёлтая есть в слове, но не здесь. Повторы
считаются честно: две «о» в догадке подсветятся дважды только если их две и в слове.

- 📖 **Свой словарь** — 693 загадываемых существительных (это ~2 года ежедневных загадок)
  и 24 тысячи допустимых словоформ; слова не из словаря отвергаются и попытку не тратят.
- 🔒 **Жёсткий режим** — по каноническим правилам: открытые буквы обязаны остаться
  на своих местах, найденные — участвовать в догадке.
- ⌨️ **Раскладка не мешает** — буквы вводятся и с русской раскладки, и с английской
  (по позициям ЙЦУКЕН, как в змейке), и с экранной клавиатуры под доской.
- 👁️ **Режим для дальтоников** — оранжевый и синий вместо зелёного с жёлтым, плюс значки
  на плитках и клавишах; состояние буквы всегда есть в подписи для скринридера.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли и доиграли.
- 📊 **Статистика** — сыграно, побед, текущая и рекордная серии и гистограмма по числу
  попыток.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Ввести букву | буква (RU или EN-раскладка) | тап по клавише под доской |
| Подтвердить слово | `Enter` | `⏎` на экранной клавиатуре |
| Стереть букву | `Backspace` | `⌫` на экранной клавиатуре |
| Сдаться / новое слово | — | кнопка в шапке окна |
| Закрыть окно | `Esc` | крестик в углу |

Экранная клавиатура нужна не только пальцу: в окне игры нет полей ввода, поэтому на
телефоне системная клавиатура не появится вовсе. Закрытое окно партию не заканчивает —
её заканчивает только кнопка «Сдаться», она же раскрывает слово и обнуляет серию.

#### Настройки

Панель **Extensions** → блок **Слова**:

| Настройка | Что делает |
|---|---|
| Жёсткий режим | Открытые буквы обязательны в следующих догадках; применяется к следующей партии |
| Режим для дальтоников | Оранжевый и синий вместо зелёного с жёлтым, плюс значки на плитках |

#### Словари

Загадываемые слова собраны из [OpenCorpora](http://opencorpora.org/) (CC BY-SA 4.0) с
отсевом по частотности из [FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(тоже CC BY-SA 4.0), поэтому файл `answers.js` распространяется под CC BY-SA 4.0 — на
остальной код STGames это не влияет. Список допустимых догадок — [danakt/russian-words](https://github.com/danakt/russian-words)
(MIT). Полные условия и порядок атрибуции — в
[`src/games/words/data/NOTICE`](src/games/words/data/NOTICE); пересобираются они офлайн
скриптом `tools/build-dictionary.mjs`, который в расширение не входит.

### Сапёр

Классическое поле с минами — с одной поправкой, ради которой всё и затевалось: по
умолчанию поле **решается логикой целиком**. Расстановка принимается, только если её
разбирает решатель, не прибегая к угадыванию, поэтому концовки «две клетки, мина в одной,
угадайте» здесь не бывает.

- 🚩 **Три уровня** — 9×9 с 10 минами, 12×12 с 20, 16×16 с 40.
- 🛡️ **Первый клик безопасен** — мины расставляются после него, и вокруг него всегда
  свободная область, а не одинокая цифра.
- 🧠 **Поле без угадывания** — включено по умолчанию, отключается в настройках.
- 🖱️ **Флажок правой кнопкой**, на телефоне — долгим нажатием.
- ⚡ **Аккорд** — клик по цифре, вокруг которой уже стоят все флажки, открывает остальных
  соседей (и средней кнопкой мыши тоже).
- ⏱️ **Таймер** и счётчик оставшихся мин.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли и доиграли.
- 📊 **Статистика по уровням** — сыграно, разминировано, лучшее время.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Двигать курсор | стрелки | — |
| Открыть клетку | `Enter` / `Space` | клик / тап |
| Поставить флажок | `F` (или `А`) | правая кнопка / долгое нажатие |
| Аккорд | — | клик по открытой цифре, средняя кнопка |
| Новое поле | — | кнопка «Новая игра» |
| Закрыть окно | `Esc` | крестик в углу |

`/minesweeper <уровень>` открывает игру сразу с нужным полем.

#### Настройки

Панель **Extensions** → блок **Сапёр**:

| Настройка | Что делает |
|---|---|
| Уровень | Размер поля и число мин; применяется к следующей партии |
| Поле без угадывания | Поле принимается, только если решается логикой целиком |
| Клик по цифре открывает соседей | Аккорд без средней кнопки — единственный способ сделать его пальцем |
| Показывать таймер | Прячет время в шапке, если оно мешает |

### Нонограмма

Японский кроссворд: числа по краям говорят, сколько клеток закрашено подряд, а из них
собирается картинка. Картинки генерируются на месте и **проверяются решателем**: принимается
только та, что восстанавливается однозначно и без перебора наугад.

- 🖼️ **Три размера** — 5×5, 10×10, 15×15.
- ✏️ **Рисование росчерком** — провели по ряду мышью или пальцем, и он закрасился целиком;
  росчерк держит строку или столбец и не сваливается на соседний.
- ❌ **Крестики** — пометка «здесь пусто»: правой кнопкой, а на телефоне переключателем
  режима под полем.
- 🔢 **Выполненные подсказки гаснут** — глазу не нужно перечитывать всю колонку чисел.
- 👀 **Подсветка ошибок** — по желанию и по умолчанию выключена: нонограмма решается
  рассуждением, и красная клетка выдаёт вывод, до которого вы ещё не дошли.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли и доиграли.
- 📊 **Статистика по размерам** — сыграно, собрано, лучшее время.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Двигать курсор | стрелки | — |
| Закрасить / стереть | `Enter` / `Space` | клик или росчерк |
| Крестик | `X` (или `Ч`) | правая кнопка, режим «крестик» |
| Новая картинка | — | кнопка «Новая» |
| Закрыть окно | `Esc` | крестик в углу |

`/nonogram <размер>` открывает игру сразу с нужным полем.

#### Настройки

Панель **Extensions** → блок **Нонограмма**:

| Настройка | Что делает |
|---|---|
| Размер | 5×5, 10×10 или 15×15; применяется к следующей картинке |
| Подсвечивать неверные клетки | Красит закрашенное не по картинке; по умолчанию выключено |
| Показывать таймер | Прячет время в шапке |

### Кроссворд

Кроссворд-скелет: сетка с блоками и банк слов рядом. Вопросов нет — задача разложить банк
так, чтобы буквы сошлись на всех пересечениях. Головоломки собраны офлайн и проверены на
**единственность**: этот банк ложится в эту сетку ровно одним способом, поэтому «а вдруг
я разложил не так, как задумано» здесь невозможно.

- 📐 **Три размера** — 7×7, 9×9, 11×11; на каждый по 60 готовых головоломок.
- 👆 **Ввод в два тапа** — тап по клетке выбирает место, тап по слову в банке ставит его
  туда. Перетаскивания нет: в модалке поверх чата на телефоне оно даёт одни промахи.
- ↔️ **Повторный тап по клетке переключает across ⇄ down** — клетка на пересечении
  принадлежит двум словам, и второе выбирается тем же нажатием.
- ↩️ **Снять слово** — тап по уже разложенному слову в банке возвращает его обратно; то же
  делает кнопка «Убрать».
- 👀 **Подсветка ошибок** — по желанию и по умолчанию выключена: скелет решается
  рассуждением, и красная клетка выдаёт вывод, до которого вы ещё не дошли.
- ⏱️ **Таймер** и счётчик оставшихся слов.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли и доразложили.
- 📊 **Статистика по размерам** — сыграно, собрано, лучшее время.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Выбрать место | стрелки (первое нажатие поперёк — смена направления) | клик по клетке (повторный — across ⇄ down) |
| Поставить слово | — | тап по слову в банке |
| Снять слово | `Enter` / `Space`, `Backspace`, `Delete` | «Убрать» или тап по разложенному слову |
| Новая головоломка | — | кнопка «Новая» |
| Закрыть окно | `Esc` | крестик в углу |

`/crossword <размер>` открывает игру сразу с нужной сеткой и берёт новую головоломку;
просто `/crossword` или плитка в хабе продолжают начатую.

#### Настройки

Панель **Extensions** → блок **Кроссворд**:

| Настройка | Что делает |
|---|---|
| Размер | 7×7, 9×9 или 11×11; применяется к следующей головоломке |
| Подсвечивать неверные слова | Отмечает слова и клетки, разошедшиеся с решением; по умолчанию выключено |
| Показывать таймер | Прячет время в шапке |

#### Головоломки

Пул собирается офлайн скриптом `tools/build-crossword.mjs`, который в расширение не входит:
укладка банка в сетку — это перебор с возвратом плюс полный пересчёт раскладок ради
единственности, и делать это на телефоне посреди партии нельзя. Банк слов производен от
[OpenCorpora](http://opencorpora.org/) (CC BY-SA 4.0) с отсевом по частотности из
[FrequencyWords](https://github.com/hermitdave/FrequencyWords) (тоже CC BY-SA 4.0), поэтому
`words.js` и собранный из него `puzzles.js` распространяются под CC BY-SA 4.0 — на
остальной код STGames это не влияет. Полные условия — в
[`src/games/crossword/data/NOTICE`](src/games/crossword/data/NOTICE).

### Балда

Классическая балда на поле 5×5: в средний ряд вписано загаданное слово, дальше игроки по
очереди ставят одну букву в пустую клетку рядом с занятой и собирают через неё слово —
связным путём по соседним клеткам. Очки равны длине слова, повторять уже собранные слова
нельзя. Партия кончается, когда поле заполнено или обе стороны спасовали подряд.

- 🤖 **Три уровня соперника** — перебор у него всегда полный (иначе «слабый» просто не
  видел бы части поля), а уровни отличаются выбором: короткое слово из найденных, среднее
  или самое длинное.
- 📖 **Словарь на 20 907 существительных** всех длин, которые физически укладываются на
  поле; в рантайме из него строится префиксное дерево, и ход соперника считается за
  единицы миллисекунд.
- 🔤 **Слово набирается путём** — тапами по буквам подряд или одним росчерком; шаг назад
  по своему же следу отменяет последний шаг.
- ⌨️ **Раскладка не мешает** — буквы вводятся и с русской раскладки, и с английской
  (по позициям ЙЦУКЕН, как в змейке и «Словах»), и с экранной клавиатуры под полем.
- ⏭️ **Пас объявляется** — если у соперника не нашлось слова, игра скажет об этом, а не
  вернёт ход «сам собой».
- 📝 **Собранные слова на виду** — двумя столбцами, свой и чужой: иначе очки меняются,
  а откуда они взялись, не видно.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли и доиграли.
- 📊 **Статистика по уровням** — сыграно, побед, поражений, ничьих и рекорд очков.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Выбрать место под букву | — | тап по пустой клетке (повторный — снять выбор) |
| Поставить букву | буква (RU или EN-раскладка) | тап по клавише под полем |
| Набрать слово | — | тапы по буквам подряд или росчерк по полю |
| Подтвердить ход | `Enter` | «Готово» |
| Отменить шаг | `Backspace` | «Отменить» |
| Пропустить ход | — | «Пас» |
| Новая партия | — | кнопка «Новая игра» |
| Закрыть окно | `Esc` | крестик в углу |

«Отменить» разбирает незавершённый ход по шагам: сначала буквы пути, потом поставленную
букву, потом сам выбор клетки. Экранная клавиатура нужна не только пальцу: в окне игры нет
полей ввода, поэтому на телефоне системная клавиатура не появится вовсе.

`/balda <уровень>` открывает игру сразу с нужным соперником и начинает новую партию;
просто `/balda` или плитка в хабе продолжают сохранённую.

#### Настройки

Панель **Extensions** → блок **Балда**:

| Настройка | Что делает |
|---|---|
| Уровень соперника | Лёгкий, средний, сложный. Применяется сразу, в том числе к идущей партии: уровень влияет только на выбор слова, а не на позицию |
| Первый ход | Вы или соперник; подхватывается следующей партией |

Размер поля настройкой не сделан намеренно: 5×5 — канон балды, а поле побольше не
помещается на телефоне вместе с клавиатурой.

#### Словарь

Тот же источник, что у «Слов»: [OpenCorpora](http://opencorpora.org/) (CC BY-SA 4.0)
с отсевом по частотности из [FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(тоже CC BY-SA 4.0), поэтому `words.js` распространяется под CC BY-SA 4.0 — на остальной
код STGames это не влияет. Порог мягче, чем у загадываемых слов «Слов»: словарь балды —
это то, что игрок вправе составить, а не то, что ему загадывают. Полные условия — в
[`src/games/balda/data/NOTICE`](src/games/balda/data/NOTICE); пересобирается словарь офлайн
скриптом `tools/build-dictionary.mjs`, который в расширение не входит.

## Установка

### Способ 1 — прямо из SillyTavern

1. Откройте панель **Extensions** (иконка с кубиками) → **Install extension**.
2. Вставьте ссылку на этот репозиторий:

   ```
   https://github.com/aika636/STGames
   ```

3. Нажмите **Install** и перезагрузите вкладку.

### Способ 2 — вручную

1. Скачайте репозиторий (**Code → Download ZIP** или `git clone`).
2. Положите папку с именем `STGames` в каталог расширений SillyTavern:

   ```
   <SillyTavern>/data/default-user/extensions/STGames
   ```

   На старых сборках путь другой:
   `<SillyTavern>/public/scripts/extensions/third-party/STGames`

3. Перезагрузите вкладку SillyTavern (Ctrl+F5).

### Обновление со старого расширения Sudoku

Старое расширение называлось **Sudoku** (репозиторий `aika636/Sudoku`, каталог
`extensions/Sudoku`) и было только судоку. При первом запуске STGames **переносит
настройки, статистику и незаконченную партию** из старого ключа настроек автоматически —
ничего делать не нужно. Старый ключ при этом остаётся нетронутым, так что откат на старую
версию расширения не теряет партию. Если вы устанавливаете STGames **рядом** со старым
Sudoku (отдельный репозиторий/каталог), убедитесь, что новое расширение уже активно в
`extensions/STGames`, и только после этого удалите старый каталог `extensions/Sudoku`. При
обновлении того же репозитория in-place папка `extensions/Sudoku` — это рабочая копия,
её удалять нельзя.

## Совместимость

Проверено на SillyTavern **1.18.0**. Расширение клиентское: без сборки, без бэкенда и без
зависимостей от npm — только ES-модули и CSS, которые браузер грузит напрямую.

## Разработка

```bash
node --check index.js     # синтаксис без браузера
npm install --no-save jsdom playwright   # dev-зависимости: jsdom для UI-тестов,
                                         # playwright для e2e; runtime-зависимостей нет
node tests/run.mjs        # все тесты (ядро без зависимостей, UI — под jsdom)
node tests/run.mjs sudoku # только тесты судоку
node tests/run.mjs snake  # только тесты змейки
node tests/run.mjs reversi # только тесты реверси
node tests/run.mjs words  # только тесты слов
node tests/run.mjs minesweeper # только тесты сапёра
node tests/run.mjs nonogram    # только тесты нонограммы
node tests/run.mjs crossword   # только тесты кроссворда
node tests/run.mjs balda       # только тесты балды

STGAMES_ST_DIR=<путь к SillyTavern> node tests/e2e/run.mjs   # e2e в живой таверне
```

Устройство кода, контракт игры и как добавить свою — в [`docs/`](docs/).
