# Sudoku

[![SillyTavern extension](https://img.shields.io/badge/SillyTavern-extension-blue)](https://github.com/SillyTavern/SillyTavern)
[![version](https://img.shields.io/badge/version-0.3.0-informational)](manifest.json)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**Мини-игра для [SillyTavern](https://github.com/SillyTavern/SillyTavern):** судоку в модальном
окне поверх чата. Открывается из меню «волшебной палочки» или командой `/sudoku`, закрывается
по Esc — и чат остаётся ровно там, где вы его оставили.

Головоломки генерируются локально в браузере: полное решение строится перебором с возвратом,
затем клетки выкалываются с проверкой того, что решение осталось единственным. Готовых наборов
пазлов в расширении нет, поэтому одинаковых досок вы не увидите.

## Коротко

- 🎲 **Четыре уровня** — лёгкий, средний, сложный, эксперт; сложность оценивается по технике,
  которой хватает для решения, а не по числу подсказок.
- ⌨️ **Ввод с клавиатуры** — `1`–`9`, стрелки, `Del`; экранного ряда цифр нет, окно остаётся
  компактным.
- ✏️ **Заметки-кандидаты** (`N`) с автоочисткой у соседних клеток.
- ↩️ **Undo/Redo** (`Ctrl+Z` / `Ctrl+Y`) — откатывается и авточистка заметок.
- 🔴 **Подсветка конфликтов** и, по желанию, **ошибочных цифр**.
- ⏱️ **Таймер** партии, счётчик оставшихся цифр.
- 🤖 **LLM не участвует** — чат не читается и не пишется, сетевых запросов нет.

## Установка

### Способ 1 — прямо из SillyTavern

1. Откройте панель **Extensions** (иконка с кубиками) → **Install extension**.
2. Вставьте ссылку на этот репозиторий:

   ```
   https://github.com/aika636/Sudoku
   ```

3. Нажмите **Install** и перезагрузите вкладку.

### Способ 2 — вручную

1. Скачайте репозиторий (**Code → Download ZIP** или `git clone`).
2. Положите папку с именем `Sudoku` в каталог расширений SillyTavern:

   ```
   <SillyTavern>/data/default-user/extensions/Sudoku
   ```

   На старых сборках путь другой:
   `<SillyTavern>/public/scripts/extensions/third-party/Sudoku`

3. Перезагрузите вкладку SillyTavern (Ctrl+F5).

## Как играть

Откройте игру кнопкой **Судоку** в меню «волшебной палочки» или командой `/sudoku`
(можно сразу с уровнем: `/sudoku hard`).

| Действие | Клавиатура | Мышь |
|---|---|---|
| Выбрать клетку | стрелки | клик (повторный — снять выделение) |
| Поставить/снять цифру | `1`–`9` | — |
| Стереть | `0`, `Delete`, `Backspace` | «Стереть» |
| Режим заметок | `N` / `Т` | «Заметки» |
| Отменить / вернуть | `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | «Отменить» / «Вернуть» |
| Закрыть окно | `Esc` | крестик в углу |

Повторный ввод той же цифры стирает её — отдельная кнопка «стереть» нужна редко.
Клавиши, которые игра обработала, до чата не доходят; всё остальное проходит к SillyTavern
насквозь.

## Настройки

Панель **Extensions** → блок **Sudoku**:

| Настройка | Что делает |
|---|---|
| Уровень сложности | С каким уровнем стартует новая партия |
| Подсвечивать конфликты | Красит клетки, которые спорят по строке, столбцу или боксу |
| Подсвечивать ошибочные цифры | Сверяет доску с решением и отмечает неверные цифры (по умолчанию выключено — это подсказка) |
| Автоматически убирать заметки | Убирает поставленную цифру из заметок соседних клеток |
| Показывать таймер | Время партии в шапке окна |

## Совместимость

Проверено на SillyTavern **1.18.0**. Расширение клиентское: без сборки, без бэкенда и без
зависимостей от npm — только ES-модули и CSS, которые браузер грузит напрямую.

## Разработка

```bash
node tests/solver.test.mjs      # решатель и операции над сеткой
node tests/generator.test.mjs   # генератор и оценка сложности
node tests/game.test.mjs        # модель партии: ходы, заметки, undo/redo, таймер
npm install --no-save jsdom && node tests/ui.test.mjs   # доска, окно, точки запуска
node tests/input.test.mjs       # ввод с клавиатуры и мыши (jsdom)
```

Устройство кода, известные грабли и проверенные API SillyTavern — в [`docs/`](docs/).
