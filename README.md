# STGames

[![SillyTavern extension](https://img.shields.io/badge/SillyTavern-extension-blue)](https://github.com/SillyTavern/SillyTavern)
[![version](https://img.shields.io/badge/version-0.4.0-informational)](manifest.json)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**Мини-игры для [SillyTavern](https://github.com/SillyTavern/SillyTavern):** платформа с
хабом, из которого открываются игры в модальном окне поверх чата. Сейчас в каталоге две
игры — судоку и змейка. Открывается из меню «волшебной палочки» (пункт «Мини-игры») или
командой `/stgames`, закрывается по Esc — и чат остаётся ровно там, где вы его оставили.

Игры генерируются и исполняются **локально в браузере**: сетевых запросов нет, а LLM в них
не участвует — чат не читается и не пишется.

## Игры

### Судоку

Классическая головоломка 9×9. Пазлы генерируются на месте: полное решение строится
перебором с возвратом, затем клетки выкалываются с проверкой того, что решение осталось
единственным. Готовых наборов пазлов нет, поэтому одинаковых досок вы не увидите.

- 🎲 **Четыре уровня** — лёгкий, средний, сложный, эксперт; сложность оценивается по
  технике, которой хватает для решения, а не по числу подсказок.
- ⌨️ **Ввод с клавиатуры** — `1`–`9`, стрелки, `Del`.
- 📱 **И с телефона** — ряд цифр под доской: он же показывает, сколько каждой цифры
  осталось выставить.
- ✏️ **Заметки-кандидаты** (`N`) с автоочисткой у соседних клеток.
- ↩️ **Undo/Redo** (`Ctrl+Z` / `Ctrl+Y`) — откатывается и авточистка заметок.
- 🔴 **Подсветка конфликтов** и, по желанию, **ошибочных цифр**.
- ⏱️ **Таймер** партии; на паузе, пока окно закрыто.
- 💾 **Партия не теряется** — закрыли окно или перезагрузили вкладку, открыли снова
  и продолжили с того же места.
- 📊 **Статистика по уровням** — сыграно, решено и лучшее время; видна в панели настроек.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Выбрать клетку | стрелки | клик (повторный — снять выделение) |
| Поставить/снять цифру | `1`–`9` | тап по цифре в ряду под доской |
| Стереть | `0`, `Delete`, `Backspace` | «Стереть» |
| Режим заметок | `N` / `Т` | «Заметки» |
| Отменить / вернуть | `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | «Отменить» / «Вернуть» |
| Закрыть окно | `Esc` | крестик в углу |

Повторный ввод той же цифры стирает её — отдельная кнопка «стереть» нужна редко.
Клавиши, которые игра обработала, до чата не доходят; всё остальное проходит к SillyTavern
насквозь.

Партия сохраняется сама — после каждого хода. Кнопка «Новая игра», смена уровня в окне
и `/sudoku <уровень>` начинают новую доску поверх сохранённой; кнопка в хабе и просто
`/sudoku` продолжают начатую.

#### Настройки

Панель **Extensions** → блок **Судоку**:

| Настройка | Что делает |
|---|---|
| Уровень сложности | С каким уровнем стартует новая партия |
| Подсвечивать конфликты | Красит клетки, которые спорят по строке, столбцу или боксу |
| Подсвечивать ошибочные цифры | Сверяет доску с решением и отмечает неверные цифры (по умолчанию выключено — это подсказка) |
| Автоматически убирать заметки | Убирает поставленную цифру из заметок соседних клеток |
| Показывать таймер | Время партии в шапке окна |

### Змейка

Классическая аркада на поле 21×21. Змейка ползёт сама, вы управляете направлением —
стрелками, свайпами по полю или d-pad'ом под ним.

- 🐍 **Счёт и длина** — счёт растёт за каждое съеденное яблоко, змейка удлиняется.
- ⏸️ **Пауза** — при уходе со вкладки или из окна игра сама ставится на паузу:
  вернувшись, вы не обнаружите труп.
- 🏆 **Рекорды сохраняются** — лучший счёт, лучшая длина и число сыгранных заездов
  лежат в панели настроек. Сам заезд сохранять нечего: смерть (или победа на полной
  доске) начинают новую партию.

#### Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Повернуть | стрелки / `W` `A` `S` `D` (и ЙЦУКЕН) | свайп по полю или стрелка на d-pad |
| Пауза | `Space` | кнопка на d-pad |
| Закрыть окно | `Esc` | крестик в углу |

## Установка

### Способ 1 — прямо из SillyTavern

1. Откройте панель **Extensions** (иконка с кубиками) → **Install extension**.
2. Вставьте ссылку на этот репозиторий:

   ```
   https://github.com/aika636/Sudoku
   ```

3. Нажмите **Install** и перезагрузите вкладку.

### Способ 2 — вручную

1. Скачайте репозиторий (**Code → Download ZIP** или `git clone`).
2. Положите папку с именем `STGames` в каталог расширений SillyTavern:

   ```
   <SillyTavern>/data/default-user/extensions/STGames
   ```

   На старых сборках путь другой:
   `<SillyTavern>/public/scripts/extensions/third-party/STGames`

3. Перезагрузите вкладку SillyTavern (Ctrl+F5).

### Обновление со старого расширения Sudoku

Старое расширение называлось **Sudoku** (репозиторий `aika636/Sudoku`, каталог
`extensions/Sudoku`) и было только судоку. При первом запуске STGames **переносит
настройки, статистику и незаконченную партию** из старого ключа настроек автоматически —
ничего делать не нужно. Старый ключ при этом остаётся нетронутым, так что откат на старую
версию расширения не теряет партию. Если вы устанавливаете STGames **рядом** со старым
Sudoku (отдельный репозиторий/каталог), убедитесь, что новое расширение уже активно в
`extensions/STGames`, и только после этого удалите старый каталог `extensions/Sudoku`. При
обновлении того же репозитория in-place папка `extensions/Sudoku` — это рабочая копия,
её удалять нельзя.

## Совместимость

Проверено на SillyTavern **1.18.0**. Расширение клиентское: без сборки, без бэкенда и без
зависимостей от npm — только ES-модули и CSS, которые браузер грузит напрямую.

## Разработка

```bash
node --check index.js     # синтаксис без браузера
npm install --no-save jsdom  # UI-тесты нуждаются в jsdom; runtime-зависимостей нет
node tests/run.mjs        # все тесты (ядро без зависимостей, UI — под jsdom)
node tests/run.mjs sudoku # только тесты судоку
node tests/run.mjs snake  # только тесты змейки
```

Устройство кода, контракт игры и как добавить свою — в [`docs/`](docs/).
